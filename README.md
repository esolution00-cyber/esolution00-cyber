## A connected Bambu-first 3D environment

The following pages are not isolated experiments. They form a connected e-solution environment around the Bambu Lab workflow: model preparation, large-format subdivision, product configuration, quotation, technical preflight and documented validation each have a dedicated surface while sharing one method.

Our current engineering priority is to deepen this Bambu-first environment and make it useful enough to support a direct, long-term technical collaboration. The underlying evidence model remains modular, so the system can evolve without losing the work already validated.

### [BambuFlow](https://bambuflow.esolution.it/)

An e-solution public technical preview for inspecting Bambu-oriented 3MF projects, defining optimization priorities and preparing a reproducible validation path through Bambu Studio Preview.

- local-first 3MF preflight in the browser;
- explicit separation between file evidence, user declarations and machine or physical checks;
- guided workflow for Bambu Lab H2S and H2C configurations;
- no printer control and no automatic print start;
- optimization engine and GitHub integration currently in development.

### [Stampa 3D](https://www.esolution.it/stampa-3d-su-richiesta/)

The e-solution workflow for uploading a model, choosing supported materials and colours, preparing dimensions and joints, obtaining a quotation and moving toward a controlled purchase.

### [ScalaForge 3D](https://www.esolution.it/scalaforge-3d/)

A browser-based preparation environment for scaling and dividing large models into printable parts, with configurable joints and tolerances that remain subject to a physical sample check.

### [Prodotti 3D](https://www.esolution.it/prodotti-3d/)

The e-solution catalogue of configurable 3D-printed products.

Together, these interfaces cover different stages of one workflow rather than presenting four unrelated products.

## Working principles

- preserve the original model and generate traceable revisions;
- measure changes through comparable slicing and G-code evidence;
- keep digital validation, Bambu Studio Preview and physical validation separate;
- never treat slicing success as proof of fit, strength or finish;
- never start a printer without explicit human authorization.
